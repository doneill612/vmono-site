<CodeTabs tabs={[{ id: "unix", label: "macOS / Linux" }, { id: "windows", label: "Windows (PowerShell)" }]}>
<Fragment slot="unix">

```sh
curl -fsSL https://github.com/doneill612/vmono/releases/latest/download/install.sh | sh
```

</Fragment>
<Fragment slot="windows">

```powershell
irm https://github.com/doneill612/vmono/releases/latest/download/install.ps1 | iex
```

</Fragment>
</CodeTabs>

The script downloads the archive for your OS and CPU from the latest [release](https://github.com/doneill612/vmono/releases), checks it against the release's `checksums.txt`, and installs `vmono` to `~/.local/bin` (`%LOCALAPPDATA%\Programs\vmono\bin` on Windows, which it adds to your user `PATH`). On macOS and Linux, make sure `~/.local/bin` is on your `PATH`. Requires git 2.30 or newer.

## Environment variables

| Variable | Does |
| --- | --- |
| `VMONO_VERSION` | Install a specific release, e.g. `v0.1.0`, instead of the latest. On macOS and Linux you can also pass it as an argument: `... \| sh -s v0.1.0` |
| `VMONO_INSTALL_DIR` | Install somewhere else |
| `VMONO_DOWNLOAD_BASE` | Download from a mirror of the releases page |

## Uninstall and verify

To uninstall, delete the `vmono` binary (and, on Windows, its folder from your `PATH`). To check what you have, run `vmono --version`.

<Callout>
A tarball downloaded in a browser on macOS is quarantined by Gatekeeper; clear it with `xattr -d com.apple.quarantine vmono`. The install script doesn't need this.
</Callout>

## From source

Requires [Go](https://go.dev/dl/) 1.25 or newer and git 2.30 or newer. Every route installs the same binary; pick the one for your platform.

<CodeTabs tabs={[{ id: "unix", label: "macOS / Linux" }, { id: "windows", label: "Windows (PowerShell)" }, { id: "go", label: "Any OS (go install)" }]}>
<Fragment slot="unix">

```sh
git clone https://github.com/doneill612/vmono
cd vmono
make install
```

</Fragment>
<Fragment slot="windows">

```powershell
git clone https://github.com/doneill612/vmono
cd vmono

# Build, stamped with the git version
$version = git describe --tags --always --dirty
go build -trimpath -ldflags "-X github.com/doneill612/vmono/internal/buildinfo.version=$version" -o bin\vmono.exe .\cmd\vmono

# Install to the same folder as the install script, and add it to your user PATH
$dir = Join-Path $env:LOCALAPPDATA 'Programs\vmono\bin'
New-Item -ItemType Directory -Force $dir | Out-Null
Copy-Item bin\vmono.exe $dir -Force
$userPath = [Environment]::GetEnvironmentVariable('Path', 'User')
if (($userPath -split ';') -notcontains $dir) {
    $newPath = (@($userPath, $dir) | Where-Object { $_ }) -join ';'
    [Environment]::SetEnvironmentVariable('Path', $newPath, 'User')
}
```

</Fragment>
<Fragment slot="go">

```sh
go install github.com/doneill612/vmono/cmd/vmono@latest
```

</Fragment>
</CodeTabs>

- **macOS and Linux** (and WSL): `make install` builds the binary and copies it to `~/.local/bin/vmono`. Override the location with `PREFIX=` or `BINDIR=`.
- **Windows**: `make` is not normally installed, so the PowerShell tab does the same steps by hand. It installs to `%LOCALAPPDATA%\Programs\vmono\bin`, the same place as the install script, so either one can replace the other. Open a new terminal afterwards so the `PATH` change takes effect.
- **go install**: needs no clone. Go puts the binary in `$(go env GOPATH)/bin` (`%USERPROFILE%\go\bin` on Windows), which must be on your `PATH`. The version is read from the module, so `vmono --version` reports the tag.

### Other tasks

The rest of the Makefile, and what to run without it:

| Task | With `make` | Without `make` (any OS) |
| --- | --- | --- |
| Build to `bin/` | `make build` | the `go build` line above |
| Test | `make test` | `go vet ./...` then `go test ./...` |
| Uninstall | `make uninstall` | delete the installed `vmono` / `vmono.exe` |
| Clean | `make clean` | delete the `bin` and `dist` folders |
| Dry-run the release build | `make snapshot` | `goreleaser release --snapshot --clean` (needs [GoReleaser](https://goreleaser.com)) |
